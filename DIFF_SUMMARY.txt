BEHAVIOR LOGIC
═══════════════════════════════════════════════════════════════════════════════

Condition 1: Show Edit Button
├─ When: !editMode && t.total_registered === 0 && t.status === "draft"
├─ Action: Displays pencil icon + "Edit" text
└─ On click: handleEditClick() → populates editData → sets editMode = true

Condition 2: Show Lock Badge
├─ When: !editMode && t.total_registered > 0
├─ Display: Lock icon + "Locked — N player(s) registered"
└─ Effect: No edit controls rendered; all fields display as read-only text

Condition 3: Show Edit Form
├─ When: editMode && editData
├─ Fields: Entry Fee, Question Count, Max Players, Registration Deadline
├─ Cancel button: Discards changes, closes form
└─ Save button: Sends to API, reloads data, shows success message
