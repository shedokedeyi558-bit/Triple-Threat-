```

       │
       ├─ Entire card: opacity 0→1, scale 0.92→1.0 (400ms spring)
       │
T=150ms ──────── Verified badge animation starts
       │
       ├─ Badge: scale 0→1, rotate -30°→0° (300ms spring)
       │
T=250ms ──────── Prize box animation starts
       │
       ├─ Prize: scale 0.9→1, opacity 0→1 (400ms spring)
       │
T=400ms ──────── All animations complete
       │
       ├─ User can interact (Play More, Withdraw, Save)
       │
T=0-2000ms ───── Confetti falls (continuous 2s)
```

## Visual Specifications

### Certificate Card
- **Border radius**: 24px
- **Border**: 2px solid rgba(232,163,61,0.5)
- **Background**: Linear gradient (135deg)
  - 0%: #0a0800
  - 50%: #1a1100
  - 100%: #0d0d0d

- **Padding**: 28px on all sides

### On Screen
```
┌─────────────────────────────┐
│  #E8A33D (Gold)             │  ← BITLYFE, Border, Accents
│  #FFE082 (Bright Gold)      │  ← Prize Amount (LARGEST)
│  #FFD700 (Bright Gold)      │  ← Gradients, Highlights
│  #0a0800 (Dark Brown)       │  ← Background Base
│  #1a1100 (Dark Brown)       │  ← Background Mid
│  #0d0d0d (Almost Black)     │  ← Background Dark
│  #FFFFFF (White)            │  ← Text (30-85% opacity)
└─────────────────────────────┘
```

### In Saved PNG
Same colors, optimized for image compression
- No transparency issues
- Colors remain vibrant
- Text remains readable
- File size ~150-200KB
